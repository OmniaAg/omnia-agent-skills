# Guardrails de diversidad visual

**Cargar cuando:** se define dirección de arte, se comparan referencias o una landing parece genérica.

## Objetivo

Crear una identidad coherente con marca, oferta y audiencia sin copiar una referencia ni repetir automáticamente el patrón “SaaS genérico”. La diversidad no significa aleatoriedad: cada decisión debe reforzar el posicionamiento.

## Ficha de dirección

Definir antes de pulir:

- Tesis visual en una frase.
- Contraste de personalidad (p. ej. preciso + humano).
- Paleta funcional y límites de acento.
- Sistema tipográfico y ritmo.
- Tratamiento de imagen/ilustración.
- Geometría, bordes, sombras y profundidad.
- Densidad, ancho y ritmo de secciones.
- Una firma visual distintiva.
- Motivo de movimiento, si existe.

## Guardrails obligatorios

- No copiar composición, artwork, copy o identidad de una referencia.
- No escoger gradientes, glassmorphism, grids de tarjetas o blobs como valor predeterminado.
- Evitar que todas las secciones usen el mismo contenedor, card y alineación.
- Mantener una jerarquía dominante; no hacer competir cinco efectos.
- Usar prueba real y contenido específico: la dirección visual no tapa placeholders.
- Preservar legibilidad, contraste, foco, responsive y rendimiento.
- No incorporar librerías visuales para una única decoración simple.

## Prueba de sustitución

Preguntar: si se cambia logo, color y copy, ¿la landing podría pertenecer a cualquier producto? Si la respuesta es sí, reforzar estructura narrativa, tratamiento de prueba, voz, assets y firma; no añadir decoración indiscriminada.

## Variación controlada

- Alternar densidad y escala entre secciones con intención narrativa.
- Permitir una ruptura de grid o tratamiento distintivo en el momento de mayor valor.
- Mantener consistencia en controles, tokens y estados aunque varíen composiciones.
- Diseñar primero una solución sólida sin animación; movimiento es una capa, no la identidad completa.
