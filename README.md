# OMNIA Agent Skills

Colección de skills para agentes de programación desarrolladas por OMNIA.

## Skills disponibles

### astro-premium-landing

Skill especializada en diseñar, construir, auditar y desplegar landing pages premium con Astro.

Incluye:

- Arquitectura Astro.
- Componentes `.astro`.
- TypeScript.
- Estrategia de estilos.
- SEO técnico.
- Accesibilidad.
- Rendimiento.
- Imágenes y assets.
- Verificación automatizada.
- Compatibilidad con Windows.
- Despliegue en distintos proveedores.

## Instalación

```bash
npx skills add https://github.com/TU-USUARIO/omnia-agent-skills --skill astro-premium-landing
```

## También puede utilizarse el formato corto:

```
npx skills add TU-USUARIO/omnia-agent-skills --skill astro-premium-landing
```
## Actualización
```
npx skills update
```
