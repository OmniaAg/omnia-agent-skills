# Arquetipos de landing pages

**Cargar cuando:** se define la narrativa, el sitemap o el orden de secciones. No usar como catálogo de plantillas rígidas.

## Selección por trabajo de conversión

| Arquetipo | Útil cuando | Secuencia habitual, adaptable |
|---|---|---|
| Captura de demanda | La intención ya es alta | Promesa → prueba → oferta → fricción/FAQ → CTA. |
| Categoría nueva | Hay que explicar el mecanismo | Problema → cambio de perspectiva → cómo funciona → evidencia → CTA. |
| Servicio premium | La confianza y el proceso deciden | Resultado → autoridad → proceso → casos → alcance → CTA. |
| Producto visual | La demostración vende | Resultado en uso → detalles → beneficios → prueba → CTA. |
| Evento/lista de espera | Fecha o exclusividad importan | Propuesta → agenda/beneficio → ponentes/prueba → logística → registro. |
| Comparativa/migración | El usuario evalúa alternativa | Dolor actual → diferencias verificables → transición → riesgo reducido → CTA. |

## Reglas obligatorias

- Elegir arquetipo desde público, nivel de conciencia, objeciones y conversión; no desde una estética de moda.
- Hacer que el hero responda qué es, para quién, resultado y siguiente acción sin depender de animación.
- Situar prueba cerca de las afirmaciones que respalda.
- Repetir CTA con contexto renovado, no con bloques idénticos.
- Mantener una acción primaria dominante y distinguir enlaces informativos.
- El orden debe sobrevivir sin CSS/JavaScript como documento comprensible.

## Preguntas de arquitectura narrativa

1. ¿Qué debe creer el visitante antes de actuar?
2. ¿Qué prueba elimina la mayor incertidumbre?
3. ¿Qué información puede retrasarse sin perjudicar la decisión?
4. ¿Qué sección tiene trabajo único y cuál repite lo anterior?
5. ¿Qué cambia para móvil cuando el espacio y la atención son menores?

## Señales de plantilla genérica

- Hero abstracto, tres tarjetas intercambiables, logos sin contexto y CTA sin oferta.
- Todas las secciones con igual ritmo, ancho y tratamiento.
- Decoración que compite con la prueba o esconde copy pendiente.
- Estadísticas sin fuente o testimonios de demostración.
