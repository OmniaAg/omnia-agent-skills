# OMNIA Agent Skills

Colección de skills para agentes de programación desarrolladas por OMNIA.

## Skills disponibles

### astro-premium-landing

Skill especializada en diseñar, construir, auditar y desplegar landing pages premium con Astro.

Incluye:

- Arquitectura Astro.
- Componentes `.astro`.
- TypeScript.
- Estrategia de estilos.
- SEO técnico.
- Accesibilidad.
- Rendimiento.
- Imágenes y assets.
- Verificación automatizada.
- Compatibilidad con Windows.
- Despliegue en distintos proveedores.

### omnia-aesthetic

Skill de identidad visual para reproducir, adaptar y auditar la estética digital de OMNIA en landings, sitios, interfaces, presentaciones y piezas de marca.

### omnia-light-mode

Skill modificadora que transforma contextualmente una interfaz basada en `omnia-aesthetic` de dark mode a light mode, preservando el diseño y reinterpretando únicamente el sistema cromático y el comportamiento del theme switch.

## Instalación

### astro-premium-landing

```bash
npx skills add https://github.com/astrolicious/agent-skills --skill astro-premium-landing
```

### omnia-aesthetic

```bash
npx skills add https://github.com/astrolicious/agent-skills --skill omnia-aesthetic
```

### omnia-light-mode

```bash
npx skills add OmniaAg/omnia-agent-skills --skill omnia-light-mode
```

## También puede utilizarse el formato corto

```bash
npx skills add astrolicious/agent-skills --skill astro-premium-landing
npx skills add astrolicious/agent-skills --skill omnia-aesthetic
```
